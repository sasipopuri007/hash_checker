Duplicate Filename Collision Avoidance

Section 5 Requirement: Never use filename alone as identity.

When multiple clients transfer different files sharing the exact same name (e.g., report.pdf), the system generates a unique UUID v4 for each transfer and isolates the file inside its dedicated directory. This guarantees zero accidental overwrites and ensures each file is verified against its own expected hash in MongoDB Atlas.
